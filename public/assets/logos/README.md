# Logos de los equipos

Los logos reales son marcas registradas: el juego no los incluye ni los descarga.
Si quieres verlos, copia aquí los tuyos. Esta carpeta está en `.gitignore` (salvo este archivo).

Un archivo por equipo, en **SVG** (preferido) o **PNG** con fondo transparente, cuadrado, de 256 px o más:

| Equipo | Archivo |
|---|---|
| Mercedes | `mercedes.svg` o `mercedes.png` |
| Ferrari | `ferrari.svg` o `ferrari.png` |
| Red Bull Racing | `red_bull.svg` o `red_bull.png` |
| McLaren | `mclaren.svg` o `mclaren.png` |
| Racing Bulls | `rb.svg` o `rb.png` |
| Alpine | `alpine.svg` o `alpine.png` |
| Haas | `haas.svg` o `haas.png` |
| Audi | `audi.svg` o `audi.png` |
| Williams | `williams.svg` o `williams.png` |
| Aston Martin | `aston_martin.svg` o `aston_martin.png` |
| Cadillac | `cadillac.svg` o `cadillac.png` |

Si falta el archivo de un equipo se muestra un escudo genérico con sus colores y sus siglas.
La pantalla de Ajustes para subirlos desde el juego llega en la Fase 8.
